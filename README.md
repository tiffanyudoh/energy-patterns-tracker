# Energy Patterns Tracker

A personal energy tracking app that identifies patterns in daily drains and restorers to inform boundary decisions.

## Live Demo
[View Live App](https://energy-patterns-tracker.vercel.app/)

## Features
- Daily energy logging with time-blocked activity selection
- Pattern detection algorithm (top 2 drains + restorers)
- Cognitive load detection for invisible labor
- Template-based recommendation engine
- Week-over-week trend tracking
- Export/import for data portability
- Mobile-responsive design

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS (custom warm neutrals palette)
- localStorage for data persistence
- Deployed on Vercel

## Design Philosophy
Minimal, analytical aesthetic inspired by quality journals.
Color-coded "ribbon bookmark" system for visual hierarchy without gamification.
